# Lenz Plus

افزونهٔ وردپرس برای افزودن امکانات به قالب عکاسی Lenz، شامل نوار ناوبری موبایل، دکمهٔ پشتیبانی شناور و قالب‌های صفحهٔ Elementor بر اساس طراحی‌های پوشهٔ `Design/`.

## نیازمندی‌ها

- WordPress 6.0 یا جدیدتر
- PHP 7.4 یا جدیدتر
- قالب Lenz برای یکپارچگی با امکانات قالب
- Elementor 3.16 یا جدیدتر برای قالب‌های صفحه
- WooCommerce برای دوره‌ها و سبد خرید (اختیاری)

## نصب

پوشهٔ [`lenz-plus/`](lenz-plus/) را در `wp-content/plugins/` کپی کنید و افزونه را از پیشخوان وردپرس فعال کنید.

## توسعه

- راهنمای پروژه، قوانین و قراردادها: [`CLAUDE.md`](CLAUDE.md)
- نقشهٔ راه و وضعیت فازها: [`docs/ROADMAP.md`](docs/ROADMAP.md)
- مستندات مرجع (قالب لنز، معماری افزونهٔ استادیار، فهرست طراحی‌ها): [`docs/reference/`](docs/reference/)
- سایت تست محلی: `bash tools/dev-site.sh` و سپس `php -d memory_limit=1024M -S 127.0.0.1:8888 -t .dev/wp`
- بررسی کد: `composer install` و سپس `vendor/bin/phpcs`
- ساخت بستهٔ نصب: `bash tools/build-zip.sh` (خروجی در `dist/`)

فایل‌های `Theme.zip` (قالب تجاری Lenz) و `Studiare-Extentions.zip` فقط مرجع توسعهٔ محلی هستند و در مخزن ثبت نمی‌شوند.

## ساختار پروژه

- `lenz-plus/`: کد و دارایی‌های افزونه
- `docs/`: نقشهٔ راه و مستندات مرجع
- `tools/`: ابزارهای ساخت دارایی‌ها، بستهٔ نصب و سایت تست
- `Design/`: طرح‌های مرجع رابط کاربری
- `phpcs.xml.dist`: تنظیمات بررسی استانداردهای کدنویسی PHP
